# onegai

Claude Code のスキルです。

作業が「あなたにしかできないこと」で止まったとき——サービスの登録、本人確認、鍵の投入、候補の可否——
Claude はチャットに手順を書き並べる代わりに、一枚のページを渡してきます。各画面への直リンク、
落とすものだけタップする候補リスト、そして最後に結果をコピーするボタンが一つ。

## 入れる

skills ディレクトリに置くだけです。

```bash
git clone https://github.com/maokao96/onegai ~/.claude/skills/onegai
```

一つのプロジェクトだけで使うなら `.claude/skills/onegai/` に置きます。

セットアップはこれで終わりです。サーバもアカウントも依存パッケージもありません。
Claude Code はセッション中に読み込みます（`~/.claude/skills/` 自体が無かった場合だけ再起動してください）。

## 使う

打ち込むものはありません。あなたの手待ちになった時点で Claude が自分で使います。
明示的に呼ぶなら `/onegai` と入力します。

## ページの届き方

Claude がアーティファクトとして公開して URL を渡すか（スマホを含めどの端末でも開けます）、
ローカルに保存してブラウザで開きます。どちらでもタップして進み、最後にボタンを一つ押して、
コピーされた文字列をチャットに貼るだけです。

## やらないこと

鍵・パスワード・認証コードをページが受け取ることはありません。それらは発行元のページから
あなたのターミナルへ直接渡ります——ページは経路に入りません。

## 中身

- `SKILL.md` — Claude が読む指示（依頼の分解のしかた、ページの渡し方、結果の読み方）
- `template.html` — ページの雛形。Claude は冒頭の `DATA` だけ書き換えて使う
