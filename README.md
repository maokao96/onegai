# onegai

Claude Code のスキルです。

外部サービスの設定・登録・本人確認・鍵の発行など、あなたにしかできない作業で手が止まったとき、
Claude はチャットに手順を書き並べる代わりに、一枚のページを渡します。
各画面への直リンクが並んだチェックリストで、終わった項目をタップし、最後にボタンを一つ押すと
結果がコピーされます。それをチャットに貼れば、Claude が続きを進めます。

GA4 との接続、Stripe の鍵の発行、DNS の設定、OAuth の許可——そういう場面のためのものです。

## 入れる

```bash
git clone https://github.com/maokao96/onegai ~/.claude/skills/onegai
```

一つのプロジェクトだけで使うなら、そのプロジェクトの直下で次を実行します。

```bash
git clone https://github.com/maokao96/onegai .claude/skills/onegai
```

サーバもアカウントも依存パッケージも要りません。反映されないときは、
Claude Code を再起動する（新しいセッションを開く）と確実です。

## 使う

打ち込むものはありません。あなたの手待ちになった時点で Claude が使います。
自分で呼ぶなら `/onegai` と入力します。

## ページの届き方

二通りあります。

**アーティファクトとして公開する** — Claude が URL を渡します。ページは Anthropic 側に保存され、
既定では非公開で、リンクを知っている人だけが開けます。スマホを含めどの端末からでも開けます。

**ローカルのファイルとして開く** — あなたの端末の外には出ません。
この場合、環境によっては最後のコピーボタンが効かないことがあります。
そのときはページが選択用のテキスト欄を出すので、そこから手でコピーしてください。

## 鍵の扱い

ページに鍵・パスワード・認証コードの入力欄はありません。自由記述の欄もありません。
それらは発行元の画面で確認したら、そのままあなたのターミナルに貼ってください。
ページは経路に入りません。

## 中身

- `SKILL.md` — Claude が読む指示
- `template.html` — ページの雛形。Claude は先頭のタイトルと `DATA` だけ書き換えて使う
