# onegai

Claude Code のスキルです。

外部サービスの設定・登録・本人確認・鍵の発行など、あなたにしかできない作業で手が止まったとき、
Claude はチャットに手順を書き並べる代わりに、**スマホで開ける一枚の作業台**を渡します。

各手順に、その画面への直リンクと、押す場所が太字で書かれています。読み切らなくても、
太字だけ拾えば手が動きます。終わったら「できた」、詰まったら「つまずいた」をタップ。
タップした時点で端末に保存されるので、リンク先を見て戻ってきても消えません。

可否を決めてほしいとき（20本の候補から出すものを選ぶ、など）は、同じページに並びます。
初期値は全部オンなので、要らないものだけ ✕ にしてください。

最後にボタンを一つ押すと結果がコピーされます。それをチャットに貼れば、Claude が続きを進めます。

GA4 との接続、Stripe の鍵の発行、DNS の設定、OAuth の許可——そういう場面のためのものです。

## 入れる

```bash
git clone https://github.com/maokao96/onegai ~/.claude/skills/onegai
```

一つのプロジェクトだけで使うなら、そのプロジェクトの直下で次を実行します。

```bash
git clone https://github.com/maokao96/onegai .claude/skills/onegai
```

サーバもアカウントも依存パッケージも要りません。反映されないときは、
Claude Code を再起動する（新しいセッションを開く）と確実です。

## 使う

打ち込むものはありません。あなたの手待ちになった時点で Claude が使います。
自分で呼ぶなら `/onegai` と入力します。

## ページの届き方

二通りあります。

**アーティファクトとして公開する** — Claude が URL を渡します。ページは Anthropic 側に保存され、
既定では非公開で、リンクを知っている人だけが開けます。スマホを含めどの端末からでも開けます。

**ローカルのファイルとして開く** — あなたの端末の外には出ません。
手元のファイルでもコピーは動きますが、ブラウザによっては効かないことがあります。
そのときは、コピーボタンが「上の文字を選んでコピー」に変わります。文字は画面に出ているので、
そこから手で取ってください。最後の結果コピーが効かないときは、選択用の欄が下に出ます。

## チェックの保存について

タップした内容は、**そのページを開いたブラウザの中だけ**に保存されます。
Anthropic にも Claude にも送られません。Claude が知るのは、あなたが最後にコピーして
貼った一塊だけです。

保存はブラウザごと・端末ごとなので、PC で付けたチェックはスマホには出ません。
プライベートウィンドウや、サイトデータを消す設定では残らないことがあります。

## 鍵の扱い

ページに鍵・パスワード・認証コードの入力欄はありません。自由記述の欄もありません。
コピー欄に載るのは、貼る先が外部サービスの設定画面である文字だけです。鍵は載りません。
鍵は発行元の画面で確認したら、そのままあなたのターミナルに貼ってください。
ページは経路に入りません。

## 中身

- `SKILL.md` — Claude が読む指示
- `template.html` — ページの雛形。Claude は先頭のタイトルと `DATA` だけ書き換えて使う
- `test/` — 雛形の検証（開発用。使うだけなら要りません）
